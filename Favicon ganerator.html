    What is a Favicon?

    A favicon (favorite icon) is a small graphic that represents a website. It appears in browser tabs, bookmarks, history lists, and even search results. Typically 16×16 or 32×32 pixels, a favicon helps users quickly identify your site among many open tabs.

    Why does every website need a favicon?

    Favicons build brand recognition and professionalism. They make your site look polished, improve user experience, and help visitors find your tab instantly. Modern browsers also use larger icons (like apple-touch-icon) when saving to home screens, so a complete favicon set is essential for a production website.

    How to use this tool

    1. Upload an image by dragging & dropping or clicking "Browse Image".
    2. Use the crop area to zoom, pan, and rotate your image.
    3. Choose a background color if you want to replace transparency.
    4. Click "Generate Favicons" to create all sizes.
    5. Download individual files or the complete ZIP package.
    6. Copy the generated HTML into your website's <head>.

    Supported image formats

    PNG, JPG, JPEG, WebP, and SVG. Maximum upload size is 20 MB. Transparency is preserved where the format supports it (PNG, WebP, SVG).

    Generated favicon sizes explained

    • favicon.ico — Classic multi-resolution icon (16, 32, 48).
    • favicon-16x16.png / 32x32 / 48x48 / 64x64 — Standard browser tab and bookmark icons.
    • apple-touch-icon.png (180×180) — iOS home screen icon.
    • android-chrome-192x192 / 512x512 — Android and PWA icons.
    • mstile-150x150.png — Windows tile icon.
    • safari-pinned-tab.svg — Monochrome SVG for Safari pinned tabs.
    • site.webmanifest — Web app manifest for Android/PWA.
    • browserconfig.xml — Legacy Windows tile configuration.
