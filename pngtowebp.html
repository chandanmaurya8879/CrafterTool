WEBP is a modern image format developed by Google that provides superior compression compared to PNG and JPG. WEBP files are typically 25–40% smaller than PNG at the same visual quality, and unlike JPG, WEBP fully supports transparency (alpha channel). It's supported by all modern browsers and is ideal for web use.
