How to use Add text to image

  • Click the Choose file: Select any image from your computer or phone.
  • Insert text: Click the Text icon on the below panel.
  • style: Change the font, size and color using the bottom of text menu bar.
  • Download Image: Click Add text and then Download Image to save it back to your device.
