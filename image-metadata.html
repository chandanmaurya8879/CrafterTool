Frequently Asked Questions

Quick answers to common questions about this tool.

Image metadata is descriptive information embedded inside the file itself. It can include file properties like dimensions, color depth, and MIME type, as well as shooting information such as camera model, lens, exposure, and GPS coordinates. This tool extracts all of that data and presents it in a clean, readable table — entirely in your browser.

EXIF (Exchangeable Image File Format) is a standard that stores camera-related metadata inside JPG and TIFF files. It typically includes camera make/model, lens type, ISO, exposure time, aperture (F-number), focal length, flash usage, orientation, GPS coordinates, and sometimes even software used to edit the image. Not all images contain EXIF — PNGs usually don't, and many images have it stripped for privacy.
